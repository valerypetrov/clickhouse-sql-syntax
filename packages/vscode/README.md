# ClickHouse SQL for VS Code

Syntax highlighting and syntax checking for [ClickHouse](https://github.com/ClickHouse/ClickHouse) SQL.

- **Colours** from a TextMate grammar generated from ClickHouse's own keyword and data type lists:
  keywords, functions, data types, strings and heredocs (`$$...$$`), numbers, comments, operators
  and query parameters (`{name:Type}`). Any colour theme works.
- **Syntax errors as you type.** Every statement is checked by
  [`clickhouse-sql-syntax`](https://github.com/valerypetrov/clickhouse-sql-syntax/tree/main/packages/core),
  a parser that follows ClickHouse's parser and reports errors in its words, such as
  `Expected one of: BY, end of query`.
- Line and block comment toggling, bracket matching and auto-closing quotes.

The checker looks at syntax only, as `clickhouse format` does: unknown tables, functions or
settings are fine. Inline data after `INSERT ... VALUES` or `FORMAT` is not checked.

## Files

The extension is used for `.chsql` and `.clickhouse.sql` files. To use it for `.sql` files as
well, add this to your user or workspace settings:

```json
"files.associations": {
  "*.sql": "clickhouse-sql"
}
```

A glob such as `"**/clickhouse/**/*.sql"` limits it to one folder. For a single file, pick
**ClickHouse SQL** with the **Change Language Mode** command.

## Development

From the root of the [repository](https://github.com/valerypetrov/clickhouse-sql-syntax):

```sh
npm install
npm run build                       # the library and the extension bundle
npm test -w packages/vscode         # type check and grammar tests, no VS Code needed
npm run test:vscode                 # the extension tests in a real VS Code, downloaded to .vscode-test
npm run package:vscode              # packages/vscode/clickhouse-sql-<version>.vsix
npm run generate -w packages/vscode # rewrite the grammar after the keyword or type lists change
```

The grammar in `syntaxes/` is generated by `scripts/generate-grammar.ts`; edit `scripts/grammar.ts`
instead of the JSON file. It uses the same scope names as `highlight()` of the library, and the
grammar tests check that both colour the test files the same way.
